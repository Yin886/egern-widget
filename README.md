# egern-widget

Egern 小组件脚本仓库。我用的 Egern 小组件都放在这里，每个小组件都在下面列有图标、名称和远程引用链接，在 Egern 里添加小组件时复制对应的远程引用链接即可。

## 小组件列表

### <img src="icons/network-radar.svg" width="26" height="26" valign="middle" alt="网络诊断雷达图标"> 网络诊断雷达

全面网络状态检测：本地网络、当前代理出口与纯净评分、流媒体解锁（Netflix / Disney+ / Spotify / TikTok / YouTube / Prime）、AI 解锁检测（ChatGPT / Claude / Gemini / Muse / Grok / Perplexity）。

远程引用链接：
